### How I Build

I like projects with a clear pressure point: something too repetitive, too fragmented, too manual, or too awkward to keep tolerating. Most repos here start from that feeling, then turn into a small tool, a reproduction, a UI wrapper, or a system prototype.

My current focus is shipping more polished public tools while keeping private experiments useful enough to become reusable pieces later.
