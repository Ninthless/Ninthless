## About me

I'm **c9 / Ninthless**. I tinker with AI tools, system utilities, and whatever starts to feel harder than it needs to be.

Most of the public work is small, focused software: provider routing for coding agents, desktop clients, Windows utilities, and reusable agent skills. I have been shipping on GitHub since 2022. The usual starting question is the same: why is this workflow still annoying?

- Building [StackFerry](https://github.com/Ninthless/StackFerry) — a desktop provider manager and router for AI coding tools
- Maintaining [agent-skills](https://github.com/Ninthless/agent-skills) — reusable skills for coding agents
- Shipping desktop and systems tools when a real friction shows up
